# 算数ミステリー・ファイル

6年生向けの、推理ゲーム型の算数アプリです。事件の証拠カードを読み、選択式（どんな矛盾があるか・どの比や式か）と数の答えで「推理を提出」します。

- 1つの HTML ファイル（index.html）で完結。インターネットがなくても動きます（CDN・外部ライブラリなし）
- タブレットのタッチ操作と PC のマウス操作の両方に対応
- 記録は localStorage（キー：`sansuMystery_data`）

## 事件の型と難易度

問題は毎回自動で作ります（seed つき。開き直しても同じ問題が残る）。難易度は事件ごとに選べます。

| 事件 | 単元 | やさしい | ふつう | むずかしい |
|---|---|---|---|---|
| 01 消えたタイムカプセルのアリバイ | 速さ | 道のりは m、カメラは早すぎる | 道のりが km（m に直す） | 証言が時速 km、コンビニが真ん中でない、カメラは早い／おそい両方 |
| 02 怪盗からの挑戦状と黄金の比率 | 比 | 青の数がはじめから同じ | 片方の比だけ何倍かしてそろえる | 両方の比を何倍か（最小公倍数）、合計が L |
| 03 なぞの暗号装置「ブラックボックス」 | 文字を使った式 | x が1ずつふえる、「＋」だけ | x が2以上ずつふえる、「－」もある | かける数・解除キーが大きい、x のふえ方がばらばら |

図・段階ヒント（3段階）・解説・落とし穴・よくある誤答へのアドバイスは、出た数に合わせて変わります。

- 対象・単元：6年／速さ・単位換算、比（連比・全体の分配）、文字を使った式（x と y）
